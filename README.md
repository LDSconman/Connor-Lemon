# Connor Lemon

Personal portfolio: https://ldsconman.github.io/Connor-Lemon/

A responsive, dependency-free static site with current experience, education, skills, and a downloadable resume. Content is based on the supplied resume.

## Preview

Run `python3 -m http.server 8000` from the repository root and open http://localhost:8000. No build step is required.

## Content

- `index.html`: portfolio content
- `css/portfolio.css`: responsive styles
- `assets/Connor-Lemon-Resume.pdf`: resume with the full portfolio URL
- `scratch.html`: redirects the former soccer page to the portfolio

The original class-project assets and mini-game remain in the repository for reference; the portfolio does not link to them.
